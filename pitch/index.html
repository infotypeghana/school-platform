The Problem
Ghana Schools Are Drowning in Paper

8,500+ private basic schools manage hundreds of students each. Every admin task is manual, error-prone, and wasteful.

📋
Manual Attendance Registers
Teachers fill paper registers daily. Reports are compiled weekly by hand. Late absences go unnoticed by parents for days.
💸
Fee Collection Chaos
Receipts written by hand. No real-time balance visibility. Fee defaulters only discovered at term end — cash flow suffers.
📝
Report Card Season = Crisis
GES grading (A1–F9) computed manually on spreadsheets. Terminals are 2-week projects. Errors are common and embarrassing.
📞
Zero Parent Communication
Parents receive no real-time updates on fees, attendance, or results. They only engage at end-of-term — or when something goes wrong.
💡 No existing solution speaks Ghana's language — GES curriculum, BECE aggregates, GHS currency, mobile-money parents, or intermittent internet.

Platform Features
Built for Every Role in Your School
🏫
Multi-School Architecture
Every school gets its own subdomain, isolated data, and branded portal. One platform, infinite schools — zero cross-contamination.
🎓
GES Grading Engine
A1–F9 grades computed automatically per GES curriculum. BECE aggregate calculation built in. PDF report cards with one click.
📲
SMS + Email Alerts
Payment receipts, fee reminders, and result notifications sent instantly to guardian phones via SMS — no app required.
🔐
2FA Security
TOTP two-factor authentication for all admin accounts. Teacher portal has separate credentials. Parent portal is admission-number + DOB.
🖐
Biometric Integration
ZKTeco fingerprint device sync via TCP. Auto-imports attendance logs — eliminates manual register entry for schools with devices.
💳
Ghanaian Payment Gateways
Paystack and Moolre integrated for subscription billing. GHS currency, mobile money support — no USD conversion friction.
📦
Data Export & Backup
Schools can export all their data (students, fees, attendance) as a ZIP with CSV files. Daily automated DB backups on the server.
📡
REST API
Full OpenAPI 3.1 spec. Token-based auth (Sanctum). Ready for a native mobile app or third-party integrations without extra work.
📝
Online Admissions
Public admission form on school's subdomain. Applications reviewed and approved by admin. Enrolled students auto-provisioned.
